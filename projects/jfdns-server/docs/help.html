jfDNS
jfDNS
=====

General Options:

    

  • [global]
    • 

  • uplink=8.8.8.8 #DNS uplink server (multiple supported)
    • 

  • uplinktimeout=2000 #uplink timeout (default 2 seconds)
    • 

  • cachetimeout=3600000 #cache timeout (default 1 hour)
    • 

  • [records]
    • 

  • {name},{type},{ttl},{value}
    • 

  • #name = full dns name
  • 

  • #type = a,aaaa,cname,mx,ptr
    • 

  • #ttl = time to live (seconds) (typically 3600)
    • 

  • #value = value for DNS (IP4,IP6,DNS Alias)
    •
