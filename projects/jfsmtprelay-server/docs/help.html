jfSMTP Relay
============

SMTP Relay will retrieve email from a POP3 Server and resend to another SMTP Server on a timer.
The POP3 server should be in Digest mode so SMTPRelay can retrieve all emails stored.

General Options:

    

  • [global]
    • 

  • pop3_host=1.2.3.4
    • 

  • pop3_port=995
    • 

  • pop3_secure=true #(default = false)
    • 

  • pop3_user=bob
    • 

  • pop3_pass=secret
    • 

  • smtp_host=5.6.7.8
    • 

  • smtp_port=25
    • 

  • smtp_secure=false #(default = false)
    • 

  • smtp_user=bob@example.com #optional
    • 

  • smtp_pass=secret #optional
    • 

  • smtp_from=bob@example.com #override from email address (optional)
    • 

  • to_filter=regexp  #regular expression to email must match (multiple supported) (else msg is discarded)
    • 

  • keepalive=true #keep pop3 connection alive (default = false)
    • 

  • interval=15 #how often to check for messages (minutes) (default=15)
    •
