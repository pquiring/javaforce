jfFTP
======

General Options:

    

  • [global]
    • 

  • port=21  #default port (supports SSL)
    • 

  • secure=990  #implicit SSL port
    • 

  • bind=192.168.0.55
    • 

  • ldap_domain=example.org
    • 

  • ldap_server=192.168.0.60
    • 

  • account={user}:{pass}
    • 

  • #one root option should be specified
    • 

  • root=/  #root folder (linux)
    • 

  • root=c:/  #root folder (windows)
    • 

  • root=/user/${user}/  #root folder (linux custom)
    • 

  • root=c:/users/${user}/  #root folder (windows custom)
    • 

  • src.ipnet=192.168.2.0/255.255.255.0 #limit client IP subnet (multiple supported)
    • 

  • src.ip=192.168.3.2 #limit client IP Address (multiple supported)
